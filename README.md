# WC2026 Scoreline Predictor

Predicts FIFA World Cup 2026 match scorelines and outcome probabilities, trained on
**49,400+ men's internationals (1872 → yesterday)**. An Elo engine (eloratings.net
formulas, validated against published rating changes) feeds ~24 pre-match features into
twin LightGBM Poisson goal-rate models blended with a time-decayed Dixon-Coles baseline.
Every prediction is a full probability matrix over scorelines — never a bare guess.

## Commands

```bash
.venv/bin/python predict.py "France vs Senegal"   # one fixture
.venv/bin/python predict.py --days 7              # next week
.venv/bin/python simulate.py --runs 10000         # tournament Monte Carlo → champion odds
.venv/bin/python backtest.py                      # walk-forward backtest + honesty gates
.venv/bin/python update.py                        # daily: refresh data → retrain → dashboard/index.html
.venv/bin/pytest                                  # test suite
```

## Honest expectations (backtested on 2,544 matches, 2024-01 → 2026-06)

| Metric | Result | Context |
|---|---|---|
| LOCK-tier picks (≥70% confidence) | **83.2%** correct (750 picks) | The headline tier — contract is ≥70% |
| W/D/L accuracy (all matches) | 60.2% | No public model exceeds ~60% honestly |
| Exact scoreline | 13.2% | Always-guessing-1-1 scores 10.1%; >15% would mean leakage |
| Actual score in our top-5 | 54.2% | |
| Ranked Probability Score | 0.166 | Bookmaker-level for this match mix |

Predictions carry confidence badges: **LOCK** (≥70%) / **STRONG** / **LEAN** / **TOSS-UP**.
The irreducible randomness of football lives in the badge, not hidden behind it.

## Data sources (all free)

- Match history: [martj42/international_results](https://github.com/martj42/international_results) (CC0, updated daily)
- Fixtures + live scores: fixturedownload.com WC2026 JSON feed
- Elo validation: eloratings.net published per-match changes
- Optional bookmaker odds: The Odds API (`ODDS_API_KEY` env or `data/odds_api_key.txt`)

## Live sentiment tracker

Real-time crowd mood during matches: Bluesky Jetstream firehose → keyword routing per
active fixture → multilingual XLM-RoBERTa sentiment (Apple MPS) → live Dash dashboard
with goal markers. Zero API costs. Match-day runbook (three terminals, or `&` them):

```bash
.venv/bin/python sentiment_collect.py     # firehose → data/sentiment.db (+ goal polling)
.venv/bin/python sentiment_score.py       # scores posts within seconds of arrival
.venv/bin/python sentiment_app.py         # dashboard at http://localhost:8050
```

Development/demo without a live match:
`.venv/bin/python sentiment_collect.py --replay tests/replay_sample.jsonl --speed 1000`
then `sentiment_score.py --once` and open the app. Honesty note: this measures *mention
mood*, not verified fan allegiance — posts naming both teams chart as "match mood".

## Player style dashboard

`players.html` (live on the site): 1,464 Big-5 players (2025-26, ≥900 min) clustered into
role archetypes — k-means within each position group on position-normalized per-90 stats,
interactive style map + per-nation tables. Rebuild after big matchdays:

```bash
.venv/bin/python players_build.py --deploy
```

Honest cuts: nationality ≈ squad proxy; players outside the Big-5 leagues aren't profiled;
market values/injuries unavailable from free sources (cut, not guessed).

## Layout

`src/fifa/` — data, elo, features, dixon_coles, gbm, matrix, ensemble, evaluate,
backtest_lib, fixtures, tournament, dashboard, runtime · `tests/` — offline test suite ·
`docs/superpowers/` — design spec + implementation plan · `dashboard/index.html` — static
dashboard regenerated by `update.py`.
